### Technical facts worth keeping

- type: fact
- source: session — recall, GitHub Actions, cadre
- text: (1) recall's default chunker has `MinChunkSize: 50`, so content shorter than 50 runes is dropped silently on upload — a store can accept a document and hold nothing. (2) recall's cosine similarity returns 0 for vectors of different widths, so an embedder-dimension mismatch returns *every* chunk in scope at score 0 in index order, not an empty result — a full, ordinary-looking answer with no relevance in it. (3) A GitHub Actions `env:` key with only comments under it parses as valid YAML with a null value and is rejected by GitHub's schema: the whole workflow fails to load, zero jobs, zero seconds, named after the file. (4) `actions/setup-go` with `cache: true` fails with `tar: Cannot open: File exists` per module if anything populated `~/go/pkg/mod` before it ran. (5) A tag pushed by a workflow using the default `GITHUB_TOKEN` does not trigger other workflows, so a release job keyed on `push: tags` never fires.
- proposed_home: `05-knowledge/technical/` — split between a recall note and a GitHub Actions note
