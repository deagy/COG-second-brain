- type: fact
- source: session
- text: A merged PR can be left un-merged in GitHub's own records. PR #6 in COG-second-brain had its merge commit on `main` with GitHub's own "Merge pull request #6" message, while the API reported `state: open`, `merged: false`, no merge event, and a `merge_commit_sha` pointing at the *predicted* merge commit rather than the real one.
