What the gates caught

P1's verifier returned FAIL:fixable because cadre still held the kernel — correct against the end state, and the criterion's wording was the lead's fault rather than the work's. P2's verifier returned FAIL:fixable on the one clause the lead had read generously in its own favour: an archived file cannot drift, but a file at HEAD reads as current regardless. Both failures were more useful than the passes.

Cadre's own test suite caught five couplings the extraction plan missed — the provider bundle, the release program model, the release gate's watched components, the engine's kernel-root resolution, and the plugin generator's version shim — each failing with a message naming exactly what broke. Separately, gh repo create refusing a name was the only thing that prevented pushing into an archived repository.
